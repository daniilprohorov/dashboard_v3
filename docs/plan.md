# План функциональности дашборда

Статус: планируемая функциональность, не описание реализованных возможностей.

Основная связка: **поездка → лог → событие → ошибка → контекст её обнаружения**. Настройки управляют сбором данных, а напоминания о ТО используют пробег, моточасы и календарное время.

## 1. Работа от питания автомобиля

Дашборд включается и выключается вместе с машиной. Автоматический сон по отсутствию ECU не требуется.

- Автоматический запуск после подачи питания.
- Восстановление настроек и доступ к истории после включения.
- Сохранение данных во время работы без зависимости от корректного выключения.
- При следующем запуске — восстановление журнала после внезапного обрыва записи.

Ограничение: без сигнала о предстоящем отключении или резервного питания нельзя гарантировать сохранение самых последних данных. Нужно определить допустимое окно потери.

## 2. Отдельная страница настроек

Все пользовательские параметры доступны на отдельной странице, сгруппированной по разделам.

| Раздел | Параметры |
|---|---|
| Экран | Яркость, дневной/ночной режим, единицы измерения |
| Автомобиль | Объём бака, предел оборотов, поправки расчётных параметров |
| Предупреждения | Включение отдельных предупреждений, пороги, задержки |
| CAN / диагностика | Автоматический или ручной выбор протокола, параметры выбранного режима |
| Запись | Включение логирования, частота записи, политика заполнения карты |
| Поездки | Правила разделения поездок |
| Обслуживание | Регламенты ТО, интервалы, отметки о выполнении |
| Дата и время | Установка времени и способ синхронизации |

Настройки сохраняются между включениями. Изменения, влияющие на расчёты и сбор данных, отмечаются в журнале, чтобы старые записи оставались понятными.

## 3. Автоматический и ручной выбор CAN-протокола

- Автоматический режим: перебор поддерживаемых вариантов, проверка корректного ответа ECU, выбор рабочего варианта.
- Ручной режим: фиксация выбранного варианта без автоматического переключения.
- Отображение текущего протокола и состояния подключения.
- Повторное обнаружение по команде пользователя.
- Сохранение последнего рабочего варианта для ускорения следующего запуска.
- Запись смены протокола и разрывов связи в лог.

Нужно разделять скорость CAN, 11-/29-битную адресацию и протокол сообщений поверх CAN. Поддержка OBD-II по CAN не означает автоматическую поддержку произвольного фирменного CAN автомобиля. До реализации нужен явный перечень поддерживаемых вариантов.

## 4. Запись, чтение и просмотр логов с карты памяти

- Запись параметров, диагностических событий и состояния связи.
- Привязка каждой записи к поездке и времени внутри неё.
- Список записей на устройстве: дата, длительность, размер, наличие ошибок.
- Просмотр выбранной записи:
  - график параметра;
  - выбор нескольких параметров для сопоставления;
  - перемещение по времени;
  - переход к предупреждению или ошибке.
- Чтение завершённых записей без подключения компьютера.
- Явные состояния: карта отсутствует, заполнена, недоступна, запись прервана.
- Настраиваемое поведение при заполнении: остановить запись либо удалять самые старые завершённые записи.

Сбой карты не должен останавливать основной экран и диагностику. Физическое подключение карты и совместимость с занятыми периферийными интерфейсами нужно проверить отдельно.

## 5. Ошибки ECU и их расшифровки

- Список DTC с кодом, текстовой расшифровкой и доступным статусом.
- Разделение текущих данных ECU и сохранённой истории устройства.
- Для каждой ошибки:
  - когда устройство впервые и последний раз её увидело;
  - в каких поездках она наблюдалась;
  - какие параметры были записаны рядом с обнаружением;
  - freeze frame, если ECU его предоставляет.
- Стандартные расшифровки доступны без интернета.
- Для неизвестных и неподдерживаемых фирменных кодов показывается исходный код, без выдуманного объяснения.

Расшифровка — описание зарегистрированной неисправности, не установленная причина поломки. Стирание ошибок в этот блок не входит.

## 6. Разделение поездок и результат каждой поездки

Базовое правило: **один цикл питания — одна поездка**. Перезапуск самой прошивки не должен незаметно выглядеть как обычное завершение поездки; такие разрывы отмечаются.

### Карточка поездки

| Группа | Результат |
|---|---|
| Время | Начало, конец при возможности определить, длительность |
| Движение | Расстояние, время движения и простоя |
| Двигатель | Моточасы за поездку — по времени работы двигателя, не экрана |
| Параметры | Минимум, максимум, среднее для подходящих параметров; время экстремумов |
| Топливо | Потрачено и средний расход, если доступны достаточно достоверные данные |
| Предупреждения | Какие возникли, когда и сколько длились |
| Ошибки ECU | Уже присутствовали при старте, впервые обнаружены в поездке, больше не наблюдались при последующей проверке |
| Качество записи | Пропуски данных, потеря ECU, проблемы записи на карту |

Из результата можно перейти к соответствующему месту в логе.

«Впервые прочитали ошибку в этой поездке» не всегда означает «ошибка возникла именно в ней». Отдельно отмечаются ошибки, присутствовавшие при первой успешной проверке, и появившиеся после проверки без них. Отсутствие ответа ECU не считается исчезновением ошибки.

## 7. Напоминания о ТО

Несколько независимых записей: масло, фильтры, ремни и любые пользовательские работы.

Для каждой записи задаются:

- название;
- интервал и точка отсчёта;
- предварительное предупреждение;
- отметка «выполнено» с сохранением истории.

### Поддерживаемые условия

| Условие | Пример |
|---|---|
| По пробегу | Через 8 000 км |
| По моточасам | Через 250 часов работы двигателя |
| Что наступит раньше | 8 000 км или 250 моточасов |
| По календарю | Конкретная дата либо через 12 месяцев после обслуживания |

Статус: **осталось → скоро → просрочено**. Подтверждение уведомления не сбрасывает интервал; его сбрасывает только отметка о выполненном обслуживании.

Для пробега нужен достоверный одометр либо явно обозначенный накопленный устройством пробег. Для календаря и дат поездок нужен источник времени, сохраняющий корректность между отключениями питания. Моточасы устройства не учитывают работу двигателя, пока устройство было отключено.
